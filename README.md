# Steam Turbine Digital Twin using Machine Learning

## Project Overview

This project presents a Machine Learning based Digital Twin framework for a steam turbine operating in a thermal power plant.

The objective is to develop a virtual representation of turbine performance using historical operational data and investigate whether important performance indicators can be estimated directly from plant operating conditions.

A digital twin is a virtual model of a physical asset that replicates its behavior using data-driven or physics-based approaches. In this project, operational parameters such as steam temperatures, steam pressures, feedwater conditions, combustion parameters, flow rates, and thermodynamic properties are used to predict key turbine and plant performance indicators.

The project demonstrates the application of data analytics and machine learning techniques to thermal power plant performance monitoring and forms a foundation for future predictive maintenance and optimization systems.

---

## Objectives

The primary objectives of this project are:

- Develop a data-driven digital twin of a steam turbine system.
- Analyze relationships between operating parameters and plant performance.
- Predict important performance indicators using machine learning.
- Identify influential operational variables through feature importance analysis.
- Explore the feasibility of digital twin applications in thermal power plants.

---

## Dataset Description

The dataset contains approximately **50,000 operational records** collected from a thermal power plant.

### Available Parameters

The dataset includes:

- Main steam temperature
- Main steam pressure
- Reheat steam temperature
- Reheat steam pressure
- Feedwater temperature
- Feedwater pressure
- Feedwater flow
- Coal flow
- Flue gas temperature
- Boiler oxygen level
- Condenser parameters
- Enthalpy values
- Oxygen concentration
- Emission parameters (SO₂, NOx)
- Various thermodynamic and process measurements

The dataset contains more than 50 process variables representing the operating condition of the power plant.

---

## Target Variables

The following performance indicators were selected as prediction targets:

### Gross Load (MW)

Represents the electrical power generated by the unit before auxiliary consumption.

### HP Turbine Efficiency (%)

Represents the performance of the High Pressure turbine section.

### NPHR (Net Plant Heat Rate)

Measures the amount of heat energy required to produce one unit of electrical energy considering plant losses.

### NTHR (Net Turbine Heat Rate)

Measures turbine-specific thermal performance.

## Methodology

### 1. Data Loading

### 2. Data Preprocessing

The following preprocessing steps were performed:

- Removal of non-numeric timestamp data

- Distribution analysis

Machine Learning models used:

- R² Score

## Digital Twin Interpretation

The digital twin developed in this project consists of three primary layers:

### Physical Layer

Represents the actual steam turbine and associated thermal power plant equipment.

### Data Layer

Contains operational measurements obtained from plant instrumentation and sensors.

### Virtual Layer

Machine learning models learn the relationship between operational parameters and performance indicators, enabling the creation of a virtual representation of turbine behavior.

This virtual model can be used to:

- Estimate performance indicators
- Monitor operating conditions
- Support decision making
- Detect abnormal performance trends

## Limitations

This project represents a first-stage data-driven digital twin and has several limitations.

### Limited Predictive Performance

Some target variables exhibited relatively low R² scores, indicating that the available input variables may not fully explain the variation in turbine performance.

### Absence of Real-Time Data

The model is trained on historical data and does not currently operate in real time.

### No Physics-Based Modeling

The digital twin is purely data-driven and does not explicitly incorporate thermodynamic equations, turbine stage calculations, or first-principles modeling.

### Sensor and Data Quality Dependence

Model accuracy depends heavily on data quality and measurement reliability.

### Single Dataset Dependency

The model has been developed and evaluated using a single operational dataset and may require validation on additional plants or operating conditions.

### Lack of Predictive Maintenance Module

The current implementation focuses on performance prediction rather than equipment health monitoring.
