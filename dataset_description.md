# Dataset Description

## Overview

The dataset contains operational measurements collected from a thermal power plant.

Total Records: ~50,000

Total Features: 53

## Feature Categories

### Steam Parameters

- Main Steam Temperature
- Main Steam Pressure
- Reheat Steam Temperature
- Reheat Steam Pressure

### Feedwater Parameters

- Feedwater Temperature
- Feedwater Pressure
- Feedwater Flow

### Combustion Parameters

- Coal Flow
- Boiler Oxygen Level
- Flue Gas Temperature

### Environmental Parameters

- SO₂ Concentration
- NOx Concentration

### Thermodynamic Parameters

- Enthalpy Values
- Pressure Measurements
- Temperature Measurements

## Target Variables

The following variables were selected as prediction targets:

1. Gross Load (MW)
2. HP Turbine Efficiency (%)
3. NPHR (Kcal/KWh)
4. NTHR (Kcal/KWh)

## Data Characteristics

The dataset represents real-world plant operating conditions and contains measurements from various operating regimes of the thermal power plant.
